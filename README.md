# seo-analyzer

Діагностика: чому сторінка слабо ранжується за запитом, якщо порівняти її з конкурентами з видачі Google.

Модулі спираються на три джерела: матеріали справи U.S. v. Google, внутрішня документація Google Search (Content Warehouse API), що потрапила у відкритий доступ у 2024 році, і документація Google Search Central.

Інструмент видає **ймовірні причини з рівнем упевненості**, а не вердикт. Кліки (Navboost), якість сайту (Q\*) і спам-сигнали Google ззовні не видно, і звіт про це прямо каже. Наскільки ознакам можна довіряти у вашій ніші, перевіряє команда `backtest`.

Приклад звіту на реальній сторінці: https://oleksiimatuznyi.com/lab/seo-analyzer/

## Швидкий старт без ключів

Потрібні Git і Python 3.11+. Встановлення займе близько 460 МБ разом із залежностями.

```bash
git clone https://github.com/sneex-seo/seo-analyzer.git
cd seo-analyzer
python -m venv .venv
.venv\Scripts\activate          # macOS і Linux: source .venv/bin/activate
pip install -e .
```

Запуск без API: конкурентів вказуєте вручну.

```bash
python -m seo_analyzer analyze --url https://site.ua/page/ --kw "ваш запит" --provider manual --competitors https://a.ua/x https://b.ua/y https://c.ua/z
```

Відкрийте `report.html`. Сторінка з обходом 50 сторінок сайту і 6 конкурентами рахується близько 30 секунд.

Без ключів позиції конкурентів невідомі, а смисловий аналіз виконується офлайн-наближенням LSA. Це робочий чорновий прогін. Для точнішого результату додайте ключі.

## Запуск із ключами

```bash
copy .env.example .env          # macOS і Linux: cp .env.example .env
```

Ключі необов'язкові, кожен вписує у `.env` свої. Щоб не збирати конкурентів вручну, зареєструйтеся в сервісі SerpApi (https://serpapi.com): він віддає видачу Google, безкоштовно 250 пошуків на місяць, один аналіз запиту витрачає 2-3 пошуки. Ключ впишіть як `SERPAPI_API_KEY`.

```bash
python -m seo_analyzer check
python -m seo_analyzer analyze --url https://site.ua/page/ --kw "іпотека для молодих сімей" --kw "молодіжна іпотека" --country ua --lang uk --out report.html --json report.json
```

`check` робить безкоштовні перевірочні запити. Самі ключі не виводяться.

## Інші команди

Історія сторінки в Search Console: покази, позиції й кліки за 16 місяців із накладанням апдейтів Google. Команда також показує, який URL сайту Google ранжує за головним запитом і коли він змінився. Потрібен `pip install -e ".[gsc]"` і `GSC_TOKEN_FILE` (OAuth-токен, лише читання) або `GSC_SERVICE_ACCOUNT_FILE` у `.env`.

```bash
python -m seo_analyzer gsc --site https://www.site.com/ --page https://www.site.com/page/ --contains seo --query "seo agency" --country ua
```

Бектест ніші: чи справді ознаки передбачають позиції саме у вас. Потрібно 30 і більше запитів однієї тематики.

```bash
python -m seo_analyzer backtest --kw-file niche.txt --country ua --lang uk --out backtest.json --profile-out niche_profile.json
```

Профіль ніші підключається до аналізу через `analyze ... --niche-profile niche_profile.json`. Упевненість діагнозів, чиї ознаки в ніші не підтвердилися, знижується.

Бектест рахує два зрізи:
- **Увесь топ-20.** Тут ознаки релевантності здебільшого відділяють нерелевантні результати (вакансії, курси, відео) від релевантних.
- **Лише сторінки за темою**, де слова запиту є в title і в тексті. Профіль ніші будується за цим зрізом, бо аналіз відповідає на запитання, чому одна релевантна сторінка нижче за іншу.

Щотижневий KPI-звіт за запитами: зведення, порівняння з минулим тижнем і базовою лінією, історія в `history.csv`.

```bash
python -m seo_analyzer gsc-kpi --site https://www.site.com/ --page https://www.site.com/page/ --query "seo agency" --country ua --baseline 2026-09-13:2026-10-10 --start-date 2026-10-19 --out-dir runs/site/weekly
```

## Що рахується

Модулі йдуть каскадом: спочатку те, що відсікає сторінку найраніше. Порядок - спрощена модель за мотивами етапів ранжування з матеріалів справи, а не копія системи Google.

| # | Модуль | Що рахує | Підстава |
|---|---|---|---|
| 1 | Індексація і техніка | статус, robots.txt (правила Google з `*` і `$`), noindex, canonical, мова й hreflang, JS-сторінки, viewport, дублі title | Google Search Central |
| 2 | Інтент | тип сторінки (товар, категорія, стаття, послуга, форум тощо) проти домінантного типу в топ-10 | Google: спершу визначається намір запиту (How Search Works) |
| 3 | Канібалізація | інша сторінка сайту у видачі, сторінки з більшою схожістю із запитом, дублі тексту | - |
| 4 | Лексика | BM25F за полями title / H1 / H2-H3 / текст / URL з лематизацією uk і ru, розриви за термінами й словосполученнями | нотатки дзвінка з Панду Наяком (2025): традиційне ранжування Google «у стилі Okapi BM25» |
| 5 | Смисл | ембединги: найкращий фрагмент (MaxP), схожість із «центром» топу, покриття підтем конкурентів і питань PAA | RankEmbed, passage ranking |
| 6 | Перелінковка | внутрішній PageRank із вагами зон посилань, «близькість до головної» (проксі `onsiteProminence`), глибина, сироти, анкори, кандидати-донори, моделювання «що якщо» | документ Google про структуру сайту, витік |
| 7 | Фокус сайту | центроїд ембедингів сайту і місце сторінки відносно нього | наближення до `siteFocusScore` / `siteRadius` із витоку |
| 8 | Зовнішні посилання | донори сторінки й домену проти конкурентів, частка анкорів із ключем, країни донорів | DataForSEO, не Google |
| 9 | AI Overviews | допуск до показу і цитування, скільки джерел AI-відповіді з топ-10 | документація Google про AI-функції |

**Як рахується впевненість.** Береться частка конкурентів вище за вас, які перевершують сторінку за ознакою. За малої вибірки ця частка стягується до 50%. Потім її коригує профіль ніші з бектесту.

## Джерела даних і вартість

Ціни на жовтень 2026 року.

| Що | Без ключів | З ключами |
|---|---|---|
| Видача | ручний список конкурентів | SerpApi: 2 пошуки за топ-20, ще 1, якщо AI Overview приходить окремим токеном, безкоштовно 250 пошуків на місяць. DataForSEO: близько $0,0035 за топ-20 і $0,002 за AI Overview. Serper: близько $0,001-0,002 |
| Ембединги | офлайн-LSA або локальна `paraphrase-multilingual-MiniLM-L12-v2` (`pip install -e ".[local]"`, близько 220 МБ) | OpenAI `text-embedding-3-small`: $0,02 за 1 млн токенів. Gemini: `gemini-embedding-001` |
| Зовнішні посилання | Open PageRank (безкоштовний ключ, 30 000 доменів на місяць): авторитет і домени-донори на рівні домену за графом Common Crawl | DataForSEO Backlinks: $0,024 за запит, для 10 конкурентів близько $0,5 на ключ. Рівень сторінки, анкори, країни |

Усі відповіді API, сторінки й вектори кешуються в `.cache/seo_analyzer.sqlite`, тому повторний запуск безкоштовний. Строки зберігання: сторінки 24 години, видача 72 години, посилання 14 днів.

## Обмеження

- JavaScript не виконується. Якщо сторінка малюється скриптами, інструмент попередить. Рендеринг через Playwright у планах.
- Сайти із захистом від ботів (Cloudflare та подібні) віддають 403. Такі конкуренти випадають із порівняння, а звіт про це попереджає.
- Search Console підключено окремими командами `gsc` і `gsc-kpi`, у звіт `analyze` ці дані поки не входять.
- Типи сторінок визначаються евристиками.
- Абсолютні значення схожості залежать від моделі ембедингів, тому порівняння всюди відносне.
- На живих ключах перевірені SerpApi, OpenAI, Open PageRank, DataForSEO Backlinks і Search Console. Видача через DataForSEO і Serper, а також ембединги Gemini написані за документацією і в роботі не запускалися.
